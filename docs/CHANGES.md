# 本整合版相对上游的修复

## 0.2.0-seamless.2 · 2026-11-06

- 旧注入器 PID 已被其他进程复用时，忽略过期记录并保留该进程；无法核实身份时仍中止停止操作。
- 壁纸设置失败后，已有 Codex 进程或已发起直接启动时，不再调用第二次 Shell 激活，避免重复开窗。
- 适配 Codex 26.1103 的 Windows 应用菜单类名、侧栏包装层与稳定输入区属性，统一顶栏底色、清除侧栏顶部缝隙、避免首页输入区重复涂色。
- 增加旧进程记录回归测试，以及推送/PR 的 Windows 包检查工作流。
- 本机验证包含浅色/深色、新旧结构、两种宽度的 8 组样式夹具；在 Codex 26.1103.3517.0 中检查实际顶栏/侧栏/输入区及连续视频解码。其他官方版本仍需实际界面验收。

## 初始整合记录

导出日期：2026-10-18。启动器基于 0.2.0；壁纸核心基于 1.7.3。导出的是实际运行修复后的本地代码，再增加通用部署适配。

- 固定居中 1600×900 物理像素窗口与目标客户区；修正 DPI/窗口边框、最终位置和多屏坐标。
- 协调器与动画并行启动官方客户端，直接调用经过注册包校验的真实程序；可复用已验证会话，关闭末个窗口后会重新激活窗口。
- CDP 监听必须属于匹配官方程序，IPv4/IPv6 均限制回环，核对浏览器身份，拒绝把其他占用端口当成 Codex。
- 注入器初次等待壳页面的观察上限改为 10 秒，跳过排除窗口，增加准备时间记录；不再仅因 endpoint 存在就认定壁纸已就绪。
- 检查实际视频背景可见、正在播放、解码帧在连续样本间增加；在 12.7–13.65 秒使用 DWM 实时缩略图衔接，13.65 秒立即交还输入，取消原视频尾部的额外覆盖。
- 慢启动使用由原动画制作的 90 秒接续视频，限制超时，保留跳过处理。接续不代表真实窗口已可操作。
- 壁纸改为当前 1280×720 H.264 MP4，保持 24fps 原速、0.9 透明度和浅色主题；不额外依赖 WebM 解码器。
- 同一个引擎、主题和官方浏览器会话可复用监视进程，避免反复重新注入。Node 保留签名、版本、路径和进程身份核验。
- 导出适配把原来的本机 CodexDreamSkin 依赖和主题偏好改成安装目录自包含；官方包版本和应用 ID 自动发现，新增一键安装、备份恢复、离线发布和 GPT 部署指引。

仅整合本次启动/壁纸功能所需的引擎源码。没有打包上游独立主题管理器、托盘、市场或整套预设；日常使用由当前主题 JSON 和启动器配置完成。
