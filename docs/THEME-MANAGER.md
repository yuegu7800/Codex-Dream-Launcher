# Dragon Studio 本地主题管理器

双击安装目录的 Theme-Manager.cmd，或桌面“Dragon Studio 主题管理器”快捷方式。

- 本地 MP4 导入、静音循环预览、手动应用；导入不会立即切换当前主题。限制为 16 MiB，建议 H.264 MP4，文件头与主题负载验证不能保证所有编码都能被 Windows 解码。
- 五套配色预设共用所选视频，不包含五套独立视频。原色、雾蓝、鼠尾草、蔷薇和纸白可选，可调壁纸透出。
- 应用前验证主题并保留旧 theme.json；当前引擎自动读取，不重启 Codex。没有壁纸会话时只保存设置，待下次壁纸模式启动生效。
- 托盘提供显示窗口、暂停/恢复、退出管理器。关闭窗口收起到托盘；退出管理器保留壁纸。隐藏管理窗口会暂停管理器自己的预览。
- 普通/壁纸启动模式只控制下次启动。暂停视频不关闭 Codex 调试端口。
- 官方 Gallery/Studio 在浏览器打开。市场集成目前是浏览入口，暂未实现原生列表、账号、下载和 ZIP 导入；不把它描述为完整主题市场。

管理器共享此安装的 skin/library 和 themes/dragon，不安装另一套引擎，不写入官方程序目录，不增加开机自启。导入视频按 SHA-256 去重，库素材及选择保留在本机。在线站点有自己的使用条款；仅访问不上传本地素材。

素材库新增入口 Wallpaper-Library.cmd，导出后直接进入本安装的视频列表；切回管理器会刷新。配色切换保留透出值，中文素材名按 UTF-8 读取。格式转换与限制见 ../wallpaper-library/README.md。
