# 启动模式与调试端口

默认保留动态壁纸。新会话由 Windows 分配可用回环端口，不再从固定 9335 顺序扫描；已有会话只在官方程序归属、回环监听和浏览器身份验证通过后复用原端口。不为迁移端口强制结束用户会话。

随机端口不是认证。本机有权限连接的程序仍可能使用 CDP；当前引擎依赖 TCP，不支持直接替换为调试管道。没有开放远程地址，也没有放宽进程/浏览器身份校验。端口释放到启动之间存在小的占用竞争，后续归属校验会拒绝错误进程，必要时普通界面回退。

双击 Normal-Startup.cmd 设置普通动画模式；Wallpaper-Startup.cmd 恢复壁纸模式。这两个入口只修改下一次启动的配置并备份原配置。保存工作并完全退出 Codex，再从原动画入口打开，才会改变运行模式。隐藏背景、停止注入器或修改配置都不会关闭已经打开的 CDP 监听。

只接受本地 MP4 视频主题；场景流、外部流和 CSP 绕过已禁用。启动前校验安装自带 Node 的固定 SHA-256，并保留 Authenticode 校验，不回退到 PATH 上的运行时。

尚未实现发布签名和启动时对所有脚本的独立可信签名校验。可被共同修改的哈希清单只检测损坏，不能证明发布者身份。没有为此修改目录 ACL，也没有自动删除任何用户资料。
