# Codex Dream Control Center

`CodexDreamControlCenter.exe` is a personal external wallpaper controller.

- Choose a local image to copy into the controller's own `assets` directory.
- Save it as the startup animation wallpaper if the existing launcher is beside this output folder.
- The workspace visual overlay is experimental and disabled by default.
- When enabled, it is click-through and only appears while the official Codex window is foregrounded.
- Stop and restore closes the overlay; it does not touch the Codex application or settings.

This program does not use injection and does not modify Codex, Euzhi, API credentials, models, or `.codex` configuration.
